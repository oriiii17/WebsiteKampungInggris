# Panduan & Daftar Prompt Gambar Game Kampung Inggris Sapen

Dokumen ini berisi standar gaya visual ilustrasi dan daftar prompt AI untuk pembuatan aset gambar seluruh game di website Kampung Inggris Sapen (RW 06, RW 07, RW 08).

---

## 1. Standar Gaya Visual (Design System)
Semua gambar game wajib mengikuti ketentuan berikut agar tampil seragam dan harmonis dengan tema website:
- **Gaya Seni:** Flat vector illustration, clean lines, friendly and educational cartoon style.
- **Palet Warna:** Mengutamakan hijau tua botol (`#14532D`), aksen kuning hangat (`#F59E0B`), krem hangat (`#FEF3C7`), dan putih bersih (`#FFFFFF`). Tanpa gradien neon atau glow mencolok.
- **Format File:** WebP (dikompresi, resolusi 512x512 px untuk ikon/item kata, 1024x576 px untuk latar belakang cerita).
- **Lokasi Penyimpanan Aset:** `public/images/games/<nama-game>/<nama-file>.webp`.

## 3. Cara Mengganti Placeholder dengan Gambar Asli
1. Generate gambar menggunakan AI generator (misal: Imagen 3, Midjourney, DALL-E) dengan memasukkan prompt di atas.
2. Simpan gambar dalam format WebP dengan rasio 1:1 (atau 16:9 untuk latar cerita) dan kompres di bawah 150 KB.
3. Letakkan file di folder tujuan di dalam direktori `public/images/games/`.
4. Komponen game akan otomatis memuat gambar sesuai jalur file yang sudah dikonfigurasi.
